# MiniRep 1.1.0

适用于《魔兽世界：熊猫人之谜》怀旧服 5.5.4（Interface 50504）。独立 Lua 插件，无需安装其他插件。

屏幕显示示例：

```text
皇帝少昊 · 崇敬 · 8,400 / 21,000（40%） · 今日 +2,000
贫民窟 · 友善 · 2,400 / 6,000（40%） · 今日 +500
```

## 安装

1. 退出游戏。在战网选择“熊猫人之谜”怀旧服，通过游戏设置旁的齿轮选择“在资源管理器中显示”，找到该客户端的目录。以该客户端实际目录为准。
2. 解压安装包，把整个 `MiniRep` 文件夹放到这个客户端的 `Interface\AddOns\` 目录中。最终文件必须位于 `Interface\AddOns\MiniRep\MiniRep.toc`，不要多套一层同名文件夹。
3. 重新启动游戏，在角色选择界面的“插件”列表中启用 MiniRep，然后进入角色。

从 1.0.0 升级：退出游戏后用新版覆盖 `Interface\AddOns\MiniRep`，保留 `WTF` 中的设置，再重新启动游戏。原来的单个声望会自动加入关注列表，位置、字号和锁定状态继续保留。此次新增 `Daily.lua` 并修改加载清单，建议完整重启客户端。

## 使用

- 初次显示“MiniRep：右键添加关注声望”。右键文字，或在聊天框输入 `/rmini`，打开设置。
- 在“关注声望”页搜索名称，点击一行添加关注；再次点击取消关注。可以同时关注多个声望，屏幕按添加顺序逐行显示。关注过多时可在屏幕面板上滚轮浏览。
- **按住 Ctrl + 左键拖动任意一行**即可移动整个面板，即使锁定也有效。无需修改锁定选项；取消锁定后，普通左键也可拖动。
- 使用 `−`、`+` 调整字号（12–28）。
- 取消“显示声望文字”可以隐藏；之后仍可输入 `/rmini` 打开设置并恢复显示。
- “重置位置”将文字移回屏幕上方中央。
- 设置按角色自动保存，退出登录或 `/reload` 后恢复；新角色默认未关注声望。

## 分类、排序与今日汇总

- “范围”按钮切换全部声望 / 仅关注。
- “分类”按钮左键切换下一分类、右键切换上一分类，选择“全部资料片 / 分类”恢复全部。分类使用游戏原生顶层分组，包括资料片、阵营、公会或非活动等；无法可靠判断归属的条目不猜测资料片。
- “排序”按钮左键向后、右键向前切换：资料片 / 分类、名称、声望值高到低 / 低到高、今日新增高到低 / 低到高。
- 声望值排序使用游戏返回的累计声望值，包含先前等级的进度。不同声望阈值不同，数值排序不等于等级或完成度排序；不可读取的数值排在末尾。
- 这些筛选和排序只作用于设置列表，屏幕仍按添加关注的顺序排列。
- “今日汇总”页展示今天有新增记录的各声望和新增合计，按新增量从高到低排列，支持搜索和翻页；取消关注的声望仍保留当日记录。

## 今日增加如何记录

屏幕每行末尾显示“今日 +N”，悬停也可查看，详细列表在 `/rmini` →“今日汇总”。“记录说明”按钮可悬停查看口径。

- 以**电脑本地自然日**为单位，午夜后切换到新一天；这不是服务器的日常任务重置时间。无声望事件时，屏幕最多约 30 秒内更新日期。
- 只累计插件运行、角色在线且已关注期间观测到的正向变化。跨等级使用累计值计算；下降不抵扣已经获得的声望，重复事件不重复计数。
- 第一次关注建立基线，不把原有声望算入今天。取消关注后保留当天累计，再次关注重新建立基线，不补算未关注期间的变化。
- 同日重登或 `/reload` 保留今日累计，但不会补算离线、插件关闭或数据不可读取期间的变化。首次安装前及升级前的收益无法追溯。
- 关闭“显示声望文字”只是隐藏面板，关注列表仍继续统计。
- 当前版本只保留**今天**的统计，跨日清空旧日累计，不提供历史查询。

记录与设置一起按角色保存在游戏管理的 `MiniRepDB` 中。通常对应该客户端下的 `WTF\Account\<账号>\<服务器>\<角色>\SavedVariables\MiniRep.lua`，由游戏在正常退出或重载时写盘；升级时保留 `WTF` 即可。

数字与百分比表示**当前等级内的进度**。升级时等级、分母和百分比一起更新。百分比保留一位小数，整数省略小数；未满时不会因四舍五入提前显示 100%。普通最高等级显示“崇拜（100%）”。友谊声望显示自己的友谊等级和阶段进度。

鼠标悬停可查看下一等级还需要多少声望。插件的选择不会改变游戏自带声望条的追踪目标。

## 常见情况

- **搜不到目标**：清空搜索词，范围选“全部声望”，分类选“全部资料片 / 分类”，并翻页。只有当前角色已发现、客户端能读取的声望会出现。打开游戏自带声望页后，在 MiniRep 设置中点击“刷新”重试。
- **暂无数据**：保留所选声望，不会将缺失数据显示为 0。可点击“刷新”或 `/reload` 后重试。
- **新发现的声望没有出现在已打开的设置里**：点击“刷新”或重新打开设置。常驻文字通过游戏事件自动更新，候选列表在打开设置或点击刷新时重建。
- **文字消失或跑偏**：输入 `/rmini`，勾选“显示声望文字”，再点击“重置位置”。
- **提示版本过期或报错**：本包声明 Interface 50504。可以输入 `/dump GetBuildInfo()` 查看自己的版本信息。请提供版本信息和具体报错文本，不能只靠勾选“加载过期插件”认定兼容。

## 验证范围

开发以当前 5.5.4 的 Blizzard UI 源码镜像为接口依据。本地检查结果见同目录的 `VALIDATION.md`。

尚未在真实魔兽世界客户端内验证渲染、鼠标交互、事件时序和角色重登后的保存行为。本地检查不能替代游戏内验收。

首轮游戏内建议：关注两个声望并对照原生面板；获得一次声望查看“今日增加”；Ctrl 拖动后 `/reload` 确认关注、位置与当日记录恢复。
