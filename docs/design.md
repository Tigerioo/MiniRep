# MiniRep 1.1：多声望关注与今日增加

2026-10-07。按用户确认的“屏幕显示 + 设置汇总”实现。此稿是当前版本设计，取代 1.0 单声望方案。

## 屏幕

每个关注声望占一行，按添加顺序排列。示例数值：

```text
皇帝少昊 · 崇敬 · 8,400 / 21,000（40%） · 今日 +2,000
贫民窟 · 友善 · 2,400 / 6,000（40%） · 今日 +500
```

常驻保留名称、等级、当前等级进度、百分比及今日新增。声望升级时等级和进度同步更新。满级显示等级和 100%，今日新增继续使用游戏能提供的真实数值。不可读数据不伪造为 0%，已记录的今日新增仍保留。

Ctrl + 左键拖动任何一行，即可移动整个面板；不改变锁定选项。普通左键仅在解锁后允许拖动。右键打开设置，鼠标悬停查看距离下一级所需声望和今日统计口径。关注项多到超出屏幕高度时可滚轮浏览。

## 设置与选择

`/rmini` 或右键打开设置，提供“关注声望”和“今日汇总”两个页签。

“关注声望”保留搜索和分页，每行明确显示“+ 关注”或“取消关注”。可以同时选择多个，也可以全部取消；设置顶部显示关注数量。

筛选：全部 / 仅关注、资料片或游戏原生顶层分类。分类来自客户端，不凭空推断缺失的资料片归属；非活动组也可选择。分类按钮左键下一项、右键上一项。

排序：资料片 / 分类、名称、累计声望值升降、今日新增升降。声望值比较累计数字，不同声望的满级阈值不同，因此不把数值排序解释成完成度排名。缺失值排在末尾。排序按钮左键下一项、右键上一项；设置排序不会改变屏幕关注顺序。

继续支持显示/隐藏、字号、锁定位置与重置位置。

## 今日增加

屏幕每行末尾显示“今日 +N”；“今日汇总”展示每个声望和今日新增总数，并按新增量降序排列。无增长时汇总显示空状态；取消关注的声望保留当天已有记录。

按电脑本地日期统计，自然日午夜切换，不采用服务器任务重置时间。当前版本只保留今天，不增加历史查询。日界检查每 30 秒运行一次，只检查日期，不轮询声望。

统计口径为关注期间观测到的正向增量：普通声望使用累计原值，友谊声望使用其独立累计值，避免跨等级进度归零影响结果。下降不扣除已获得数值；重复事件不重复增加。

首次关注、重新登录、重新关注及数据恢复时先建立基线，不补算未观测的间隔。同日重载与重登保留已经记录的累计。隐藏面板不停止统计，取消关注才停止该项统计。

配置和今日累计按角色存入游戏 SavedVariables 的 `MiniRepDB`；正常退出或 `/reload` 时由游戏写盘。关注列表存为有序的 ID/名称列表，当前读数与统计基线仅保留在内存中。旧版单个声望自动迁移，保留字号和位置。

## 实现与验证

`Core.lua` 管理迁移、关注和事件；`Reputation.lua` 读取普通/友谊声望与原生分类；新增 `Daily.lua` 管理每日正向累计；`Display.lua` 绘制多行并处理 Ctrl 拖动；`Options.lua` 提供筛选排序和今日汇总。

版本声明仍为 Mists Classic 5.5.4 / Interface 50504。本地 Lua 5.1 语法、51 项数据检查与模拟交互流程通过，尚未在真实游戏中验证渲染和事件时序。详见 [验证记录](../MiniRep/VALIDATION.md) 和 [使用说明](../MiniRep/README.md)。
